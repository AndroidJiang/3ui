# 乐月母婴积分商城原型

这是一个基于HTML、Tailwind CSS和Font Awesome的母婴积分商城小程序原型设计。该原型展示了用户如何在小程序中浏览母婴商品、查看个人信息以及使用积分兑换商品的流程。

## 功能特点

- **登录页面**：提供微信一键登录和手机号登录两种方式
- **首页**：展示母婴商品列表，每行两个商品，包含图片、名称、所需积分和兑换按钮
- **我的页面**：显示用户头像、昵称、积分余额、兑换订单和联系客服
- **兑换页面**：填写联系人信息和手机号码，确认兑换，并以弹窗形式显示兑换成功状态

## 技术实现

- HTML5 构建页面结构
- Tailwind CSS 提供基础样式支持
- Font Awesome 提供图标资源
- 原生JavaScript实现交互逻辑

## 文件结构

- `index.html` - 项目总览页面，用于展示所有设计
- `login.html` - 登录页面，提供微信和手机号登录方式
- `home.html` - 首页，展示商品列表
- `profile.html` - 我的页面，展示用户信息
- `exchange.html` - 兑换页面，包含兑换成功弹窗
- `styles.css` - 自定义样式文件
- `all-views.html` - 完整流程预览页面
- `README.md` - 项目说明文档

## 页面预览方式

1. 打开 `index.html` 文件
2. 点击对应按钮访问不同页面
3. 或打开 `all-views.html` 查看完整用户流程

## 设计说明

- 使用粉色系主题，打造温馨的母婴商城风格
- 界面尺寸精确对应iPhone X/XS/11 Pro (375×812px)
- 模拟了iPhone真实外观，包括边框、圆角和顶部状态栏设计
- 页面布局根据375px宽度进行优化，确保内容正确显示
- 使用真实母婴产品图片，提升视觉体验
- 包含微信小程序风格的顶部状态栏及底部导航栏

## 交互说明

- 点击登录页面的登录按钮进入首页
- 点击底部导航栏可在首页和我的页面之间切换
- 点击商品上的兑换按钮跳转到兑换页面
- 在兑换页面填写信息后点击确认完成兑换
- 兑换成功后显示成功弹窗，点击按钮返回首页
- 个人中心的退出登录按钮返回登录页面

## 本地运行

直接在浏览器中打开 `index.html` 文件即可预览项目入口，或打开 `all-views.html` 查看完整用户操作流程。

## 设计参考

本原型参考了真实的微信小程序界面设计：
- 采用类似微信小程序的界面结构
- 使用粉色作为主色调，营造母婴产品的温馨氛围
- 遵循微信小程序的交互模式和导航方式
- 所有内部页面宽度固定为375px，适配iPhone标准尺寸
